# Bank Customer Churn Analysis

## Internship Project - Cognetix Technology

This project analyzes bank customer churn data using Python, Pandas, Matplotlib, and Seaborn to identify the major factors influencing customer attrition.

---

## Objective

The main objective of this project is to:
- Analyze customer churn behavior
- Study customer attributes such as age, balance, tenure, and credit score
- Identify patterns influencing customer exit
- Perform correlation analysis
- Visualize customer churn trends using charts and heatmaps

---

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook
- VS Code

---

## Key Insights

- Customers with higher age showed greater churn tendency.
- Higher account balance customers were more likely to leave the bank.
- Credit score showed weaker correlation with churn.
- Correlation analysis helped identify relationships between customer attributes and churn behavior.
- Data visualization effectively highlighted churn patterns and customer trends.

---

## Conclusion

This project demonstrates how customer churn data can be analyzed using Python and data analytics techniques.

The analysis helped identify important factors influencing customer attrition and provided meaningful insights that can support customer retention strategies in the banking sector.
